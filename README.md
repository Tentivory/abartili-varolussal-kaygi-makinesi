# Abartılı Varoluşsal Kaygı Makinesi

Bu repository, insanlığın en büyük sorununu çözmek için yaratılmıştır: **Neden buradayız?**

Ama aslında çözmez. Sadece sorar. Ve bekler. Ve tekrar sorar.

## Nasıl Çalışır?

```bash
python kaygi.py
```

Çalıştırın. Bekleyin. Varoluşunuzu sorgulayın. Tekrar bekleyin. Çay için.

Bu makine, bilimsel olarak kanıtlanmış (kanıtlanmamış) yöntemlerle sizi derin bir düşünceye iter. Ya da uyutur.

## Özellikler

- Tamamen Türkçe felsefi sorular
- Rastgele bekleme süreleri (sanki düşünüyormuş gibi)
- Hiçbir şey yapmama sanatında ustalaşmış kod
- %100 absürt, %0 faydalı

## Uyarı

Bu kodu çalıştırmak hayatınızı değiştirmez. Ama değiştirdiğini düşündürür. O yüzden dikkatli olun.
